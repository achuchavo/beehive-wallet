# 🐝 비하이브 월렛 (Beehive Wallet)

메디블록(MED)을 시작으로 하는 코스모스 생태계용 **비수탁형(논커스터디얼) 지갑**입니다. 지갑을
추가하고, 잔액을 확인하고, 전송·스테이킹하며, **관심 주소에서 자금이 움직이는 순간 알림**을
받아보세요.

**서비스 주소:** https://wallet.beehive.kr

## 단 하나의 원칙: 개인키는 절대 기기를 벗어나지 않습니다

개인키와 시드 문구는 **오직 사용자의 브라우저 안에만** 존재하며, 사용자의 비밀번호로 암호화됩니다.
트랜잭션은 CosmJS를 통해 기기에서 직접 서명되고, *서명된 데이터만* 외부로 전송됩니다. 서버는 공개
데이터(계정 이메일, 주소, 알림 설정)만 저장하며 `api/`, `watcher/`, 데이터베이스 어디에서도 키를
다루지 않습니다.

**서버가 완전히 탈취되더라도 자금은 안전합니다** — 서버에는 훔칠 키 자체가 없기 때문입니다.

## 실행 중인 코드를 직접 검증하세요

키를 다룰 수 있는 유일한 코드는 브라우저에서 실행되는 코드이므로, 이를 검증 가능하도록 만들었습니다:

- **재현 가능한 빌드** — 누구나 릴리스를 다시 빌드하면 바이트 단위로 동일한 파일을 얻습니다.
- **공개된 해시 + 빌드 출처 증명(provenance)** — 각 릴리스에는 SHA-256 해시와, 해당 파일이 이
  공개 소스에서 나왔음을 증명하는 Sigstore 증명이 포함됩니다.
- **앱 내 배지** — 화면 하단의 `Build <커밋> · Verify` 표시가 실행 중인 사이트를 정확한 커밋과
  연결합니다.

자세한 방법: **[docs/VERIFYING-THE-BUILD.md](docs/VERIFYING-THE-BUILD.md)**

> 솔직한 한계: 웹사이트이기 때문에 재현 가능한 빌드와 해시로 변조를 *탐지*할 수는 있지만, 웹 앱
> 하나만으로 100% 변조를 막을 수는 없습니다. 이 점을 숨기지 않고 밝힙니다.

## 주요 기능

- 비수탁형 지갑 생성/가져오기, 잔액 조회, 전송·수신
- 스테이킹 — 위임 및 리워드 수령 (비하이브 검증인은 수수료 **무료**)
- 거래 내역
- **출금 트랜잭션 알림** — 관심 있는 모든 주소에 대해 (핵심 기능)
- 지원 체인: 메디블록, 치와와(Chihuahua)

## 기술 스택

- **프론트엔드:** React 19 · TypeScript · Vite · CosmJS · Tailwind
- **API:** PHP · MySQL
- **와처(Watcher):** 출금 트랜잭션을 감지해 알림을 발생시키는 Python 데몬

## 개발

```bash
cd app
npm install
npm run dev
```

백엔드 설정, 마이그레이션, 배포 관련 내용은 [`docs/`](docs/) 폴더를 참고하세요
(`deploying-production.md`, `operations.md`, `schema.sql`).
